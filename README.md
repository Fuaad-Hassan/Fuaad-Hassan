## 📂 Featured Projects

### ⚙️ [Config-Driven Data Quality Pipeline](https://github.com/Fuaad-Hassan/data_quality_pipeline)
A resilient ETL pipeline leveraging a dead-letter queue architecture to guarantee high data reliability. It validates incoming payloads against decoupled YAML contracts using Polars, automatically routing malformed records into a PostgreSQL JSONB quarantine layer for seamless inspection and recovery.

<br/>

### 🩺 [NHANES Hypertension Project](https://github.com/Fuaad-Hassan/nhanes_hypertension_project)
A comprehensive exploratory data analysis (EDA) and statistical modeling project. By analyzing NHANES public health datasets, this project uncovers key demographic correlations and critical risk factors associated with hypertension.
